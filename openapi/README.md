# Генерация клиентов API

`npm run api:generate` экспортирует контракт Cure из Zod и запускает Orval.
Команда не запускает серверы и не обращается в сеть. Результаты генерации
хранятся в Git; обычная сборка использует готовые файлы.

- `cure.json` — генерируется из `src/lib/contracts.ts`.
- `vendor/who.json` — WHO ICD API: <https://id.who.int/swagger/v2/swagger.json>.
- `vendor/orphadata.json` — Orphadata: <https://api.orphadata.com/openapi.json>.

Внешние спецификации получены 7 ноября 2026 года. Для обновления замените
соответствующий публичный JSON и запустите генерацию. `orval.config.ts`
отбирает только используемые операции. Клиенты WHO и Orphadata используются
на сервере, клиент Cure — в маршрутах `/d` и `/m`. Все импорты используют `@/`.

Orval генерирует HTTP-клиенты и типы, Zod проверяет данные во время выполнения.
В публичный код не передаются токен и ключи WHO. Локальные записи остаются
в TanStack DB; LRU кеш сервера не заменяет их и не кеширует авторизацию.
