# Состояние разработки Cure

Источник продуктового состава: `README.md`. Карта страниц в README описывает весь продукт; таблица ниже фиксирует фактическое состояние кода, а не объявляет весь продукт готовым.

| Раздел                                                                          | Состояние                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Главная desktop/mobile, язык, тема, Google OAuth                                | Реализованы в коде; вход в облаке и браузерный сценарий этой итерацией не проверялись                                                                                                                                                                          |
| Рабочий обзор                                                                   | Есть отдельные desktop/mobile-страницы ближайших назначенных задач, приглашений, недавних исследований и отклонённых изменений выбранной организации; ближайшие визиты открытого клинического пространства подключены; рекомендации пока отсутствуют           |
| Каталоги специалистов и организаций                                             | Реализованы первые страницы, поиск по загруженным записям и постоянный публичный кеш; серверная выборка пока ограничена первыми 200 записями                                                                                                                   |
| Отдельные публичные профили и страницы организаций                              | Есть самостоятельные desktop/mobile-страницы с постоянным кешем только опубликованных полей; контакты для сотрудничества, состав команды и отдельные публичные исследования организации ещё не подключены                                                      |
| Профессиональный профиль и членства                                             | Есть сервер и интерфейс; квалификация и членство подтверждаются внутренними функциями оператора; офлайн-редактирование ещё не завершено                                                                                                                        |
| Пациенты и роли                                                                 | Базовый CRUD врача, чтение разрешённых структурированных данных исследователем, выдача и отзыв доступа; добавлены отдельные записи анамнеза, аллергий, препаратов и обследований; расширенный сбор и вложения ещё не завершены                                 |
| Офлайн пациентов                                                                | Шифруемые коллекции и очередь, восстановление, версии и идемпотентность проверены в интеграционном тесте; реальные браузеры и несколько вкладок ещё не проверены                                                                                               |
| Полная карта пациента, согласия, визиты и опросники                             | Есть отдельные страницы карты и согласий, история, получатели, категории, сроки, ограничение чтения и офлайн-очередь; анамнез, аллергии, препараты и результаты обследований подключены; клинические визиты подключены; подписи и опросники ещё не реализованы |
| Подбор партнёров, предложения, команды и переписка                              | Есть страницы команды и входящих приглашений, шифруемая очередь решений, роли, отзыв и конфликты; обсуждения и задачи проекта подключены; подбор, учёт вклада и авторство ещё не реализованы                                                                   |
| Открытые исследования, проекты, протоколы и проведение                          | Есть публичные каталоги/detail, закрытые проекты с шифруемой офлайн-очередью, серверные версии протокола и проверка набора; интерфейс версий протокола с офлайн-записью подключён; проведение ещё не реализовано                                               |
| Регистры и конструктор форм                                                     | Ещё не реализованы                                                                                                                                                                                                                                             |
| Когорты, профессиональная аналитика и отчёты                                    | Есть локальный отбор по полу и точным кодам диагнозов, ANY/ALL, исключения, схема отбора, полнота данных, таблицы и график; расширенная статистика, сохранение и экспорт ещё не реализованы                                                                    |
| Обмен наборами и федеративный анализ                                            | Ещё не реализованы                                                                                                                                                                                                                                             |
| Каталоги публикаций и грантов, библиотека и обзоры                              | Внешний поиск PubMed есть в инструментах; отдельные страницы и рабочие сценарии ещё не реализованы                                                                                                                                                             |
| AI-чат и WebMCP с паритетом действий                                            | Серверные AI-интеграции и проверка подключения есть; чат, инструменты действий и WebMCP ещё не реализованы                                                                                                                                                     |
| Управление организацией, интеграции, импорт, политики                           | Только базовая серверная модель и внутренние функции подтверждения; интерфейсы ещё не реализованы                                                                                                                                                              |
| Уведомления, поддержка, публичные help/privacy/terms                            | Ещё не реализованы                                                                                                                                                                                                                                             |
| Региональные правила, FHIR/DICOM, резервирование, аудит всех чтений и экспортов | Ещё не реализованы                                                                                                                                                                                                                                             |

Ближайшие зависимости: визиты исследований, опросники и расширенные категории согласия → регистры и конструктор форм → сохранение анализов и расширенная статистика → единый API действий для интерфейса, AI и WebMCP → остальные публичные и административные сценарии. Состав README не сокращается до текущего этапа.

Исследования и текущие ограничения: `docs/research-workspaces.md`.
