# Состояние разработки Cure

Источник продуктового состава: `README.md`. Карта страниц в README описывает весь продукт; таблица ниже фиксирует фактическое состояние кода, а не объявляет весь продукт готовым.

| Раздел                                                                          | Состояние                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Главная desktop/mobile, язык, тема, Google OAuth                                | Реализованы в коде; вход в облаке и браузерный сценарий этой итерацией не проверялись                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Рабочий обзор                                                                   | Есть отдельные desktop/mobile-страницы ближайших назначенных задач, приглашений, недавних исследований и отклонённых изменений выбранной организации; ближайшие визиты и назначенные врачу рассмотрения событий открытого клинического пространства подключены; рекомендации пока отсутствуют                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Каталоги специалистов и организаций                                             | Реализованы первые страницы, поиск по загруженным записям и постоянный публичный кеш; серверная выборка пока ограничена первыми 200 записями                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Отдельные публичные профили и страницы организаций                              | Есть самостоятельные desktop/mobile-страницы с постоянным кешем только опубликованных полей; контакты для сотрудничества, состав команды и отдельные публичные исследования организации ещё не подключены                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Профессиональный профиль и членства                                             | Есть сервер и интерфейс; квалификация и членство подтверждаются внутренними функциями оператора; офлайн-редактирование ещё не завершено                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Пациенты и роли                                                                 | CRUD врача, поиск и фильтры, страницы списка, кандидаты в дубликаты, чтение разрешённых данных исследователем, выдача и отзыв доступа; добавлены отдельные записи анамнеза, аллергий, препаратов и обследований; расширенный сбор и вложения ещё не завершены                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Офлайн пациентов                                                                | Шифруемые коллекции и очередь, восстановление, версии и идемпотентность проверены в интеграционном тесте; реальные браузеры и несколько вкладок ещё не проверены                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Полная карта пациента, согласия, визиты и опросники                             | Есть отдельные страницы карты и согласий, история, получатели, категории, сроки, ограничение чтения и офлайн-очередь; анамнез, аллергии, препараты и результаты обследований подключены; клинические визиты и полное содержимое редакций карты, согласий и клинических записей с автором и временем подключены; шаблонные опросники и заполнение врачом подключены; подписи и самостоятельный ввод пациентом ещё отсутствуют                                                                                                                                                                                                                                                                                           |
| Подбор партнёров, предложения, команды и переписка                              | Есть страницы команды и входящих приглашений, шифруемая очередь решений, роли, отзыв и конфликты; обсуждения и задачи проекта подключены; личные декларации вклада и интересов, версии соглашений об авторстве и личные решения с офлайн-очередью подключены; подбор ещё не реализован                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Открытые исследования, проекты, протоколы и проведение                          | Есть публичные каталоги/detail, закрытые проекты с шифруемой офлайн-очередью, серверные версии протокола и проверка набора; интерфейс версий протокола с офлайн-записью подключён; врач фиксирует скрининг, включение, отказ, выбытие и завершение пациента с проверкой протокола, этики и отдельного согласия; журнал набора своей клиники с фильтрами и контролем срока согласий подключён; исследовательские визиты с участием, согласиями, окнами, результатами и офлайн-очередью подключены; нежелательные явления, отклонения, назначенное врачебное рассмотрение, сроки и офлайн-очередь своей клиники подключены; межцентровый журнал, регуляторные уведомления и автоматическое расписание ещё не реализованы |
| Регистры и конструктор форм                                                     | Есть версии шаблонов, шесть типов вопросов, условные ветки, вычисляемые шкалы с баллами и коэффициентами, правила и закрытие новых ответов; регистры и валидированные клинические инструменты ещё не реализованы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Когорты, профессиональная аналитика и отчёты                                    | Есть локальный отбор по полу и точным кодам диагнозов, ANY/ALL, исключения, схема отбора, полнота данных, таблицы, график и личные сохранённые критерии с офлайн-очередью; бинарное сравнение когорт с точными интервалами долей и χ² при выполнении условий; фиксированные выборки, модели, временные показатели и экспорт ещё не реализованы                                                                                                                                                                                                                                                                                                                                                                         |
| Обмен наборами и федеративный анализ                                            | Ещё не реализованы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Каталоги публикаций и грантов, библиотека и обзоры                              | Личная библиотека с DOI/PMID, подборками, метками, заметками, версиями, постраничным PubMed и шифруемой офлайн-очередью подключена; совместные обзоры, гранты, метаанализ и публикационные отчёты ещё не реализованы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| AI-чат и WebMCP с паритетом действий                                            | Серверные AI-интеграции и проверка подключения есть; чат, инструменты действий и WebMCP ещё не реализованы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Управление организацией, интеграции, импорт, политики                           | Только базовая серверная модель и внутренние функции подтверждения; интерфейсы ещё не реализованы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Уведомления, поддержка, публичные help/privacy/terms                            | Ещё не реализованы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Региональные правила, FHIR/DICOM, резервирование, аудит всех чтений и экспортов | Ещё не реализованы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

Ближайшие зависимости: межцентровый журнал набора, расписание протокола, уведомления и расширенные категории согласия → регистры и расширение конструктора форм → фиксированные выборки и расширенная статистика → единый API действий для интерфейса, AI и WebMCP → остальные публичные и административные сценарии. Состав README не сокращается до текущего этапа.
