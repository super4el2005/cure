# Межцентровый журнал набора

`/d/projects/:id/enrollment` и `/m/projects/:id/enrollment` показывают межцентровый обзор над журналом набора выбранной клиники. Серверный запрос `convex/recruitment.ts` собирает подтверждённые записи участия всех центров проекта и возвращает только агрегаты: распределение текущих решений по шести состояниям, число включённых с истёкшим согласием и дату последнего подтверждённого обновления центра (UTC).

## Доступ и состав

Чтение открыто любому активному участнику команды исследования, включая роль наблюдателя; участие проверяется на сервере для каждого запроса. Наблюдатель клиники и исследователь видят одинаковые агрегаты. Посторонний пользователь и снятый участник получают отказ, несуществующий проект — тот же отказ без различения. Несовпадение переданного идентификатора с сессией отклоняется.

В ответе нет идентификаторов пациентов, имён, дат отдельных событий, причин решений и документов согласия. Агрегация считает последнее решение каждой записи участия; история переходов и поток включения за период не показываются. Истёкшее согласие учитывается только у действующего участника, дата окончания включительна. Удалённые записи и записи других проектов исключены. Центр без каталожной карточки показывается с идентификатором вместо названия.

## Сеть и границы

Обзор требует сети и активной сессии и не кешируется для офлайн-работы. Изменения, ожидающие отправки из локального пространства клиники, попадают в обзор только после серверного подтверждения, поэтому журнал клиники может временно опережать обзор. Журнал выбранной клиники по-прежнему доступен только врачу из локального зашифрованного набора.

## Проверки

Unit-тесты модели проверяют агрегацию по центрам, включительность даты согласия, исключение удалённых и чужих записей, детерминированный порядок и отсутствие персональных полей в результате. `convex-test` проверяет доступ участников, отказ постороннему и при смене учётной записи, агрегаты двух центров и исчезновение удалённой записи. Интерактивный браузерный сценарий не проверялся: действует запрет из AGENTS.md. Регуляторные уведомления, автоматическое расписание и исторические срезы остаются в составе README и не подключены.
