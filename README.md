## Стек

- TypeScript, React 19.
- TanStack Start — SSR; TanStack Router — маршрутизация.
- Rsbuild / Rspack — сборка.
- Mantine, Recharts, React Icons — интерфейс.
- Convex — backend и база данных.
- Axios — HTTP; TanStack Query — запросы; TanStack DB — локальные данные.
- Better Auth — авторизация.
- Bowser — определение устройства.
- Orval, Zod — API-клиенты, контракты и валидация.
- lru-cache — серверный кеш.
- openid-client — OAuth WHO.
- html-to-text, geolib, js-cookie — HTML, география и cookies.
- Lingui — русский и английский языки.
- Serwist — PWA и офлайн-оболочка.
- GigaChat SDK, TanStack AI — интеграция AI.
- Rstest, Playwright — тестирование.
- Rslint, Oxfmt — линтер и форматирование.
- Husky, lint-staged, Commitlint — Git-хуки и Conventional Commits.
- Vercel — хостинг.
- Sentry — ошибки, события, логи и трассы.

## Используемые API

- Sentry ingest — облачная телеметрия при подключённом DSN.
- Google OAuth — вход через Google.
- GigaChat — AI по умолчанию.
- OpenAI, Anthropic, Google Gemini, OpenRouter, DeepSeek, Groq — AI с ключом пользователя.
- OpenAI-совместимые API — пользовательский endpoint.
- ROR API v2 — образовательные организации.
- OpenStreetMap / Overpass — больницы и клиники по координатам.
- Geofabrik — региональные выгрузки OSM.
- WHO ICD API v2 — МКБ-10 и МКБ-11.
- PubMed / NCBI E-utilities — медицинские публикации.
- Orphadata — редкие заболевания.
